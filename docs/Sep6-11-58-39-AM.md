## Prompt

Make the README honest about what actually shows up in the demo. Mission
auto-adjustment mid-flight, for example, is not something we do now — it is part
of our philosophy for building the product, so say that instead of implying it
ships today.

## Overclaims removed

- **"Interrupt a planned mission by gesture mid-flight."** Nothing joins the
  planner, the 3D world, and gesture control into a live override. Moved to a new
  "What we believe, and have not built yet" section, labelled as direction.
- **"Open palm triggers emergency stop."** In the demo the open palm means *hold
  station 3.5 m above me*. Stopping is releasing the pose, plus the **Stop drone**
  control. The palm-as-emergency-stop idea moved to the philosophy section.
- **"Move — follow directional intent."** No phone gesture maps to a directional
  dash; `forward`/`left`/`right` exist in `phone-flight.ts` but nothing emits them.
  Dropped from the command table.
- **"Spoken commands in development"** softened to: a local LLM compiles written
  instructions to mission JSON on a separate path; no speech reaches the demo.
- The workstream list now says which four are the live demo path and which three
  sit beside it.

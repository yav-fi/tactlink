# Build waypoint planner

Completed: September 5, 2026, 04:30:14 PM EDT (America/New_York, UTC-04:00).

Prompt: "sounds good, lets build it" after agreeing to click, typed, and spoken
waypoint commands with Mission Planner export first.

Added a separate responsive 2D planner served at /planner by the flight bridge.
It supports direct map waypoints, orbit centers, command forms, typed clauses,
editing/reordering/deletion, persistent local drafts, and exact-draft WPL export.
Added direct local waypoint grammar sharing the existing state/geometry limits.
Added local CPU INT8 base.en transcription, a push-to-talk AudioWorklet capture
path, WAV validation, optional dependency/model setup, and editable transcripts.
Recordings are not persisted. The offline coordinate map supports optional
visible OSM street tiles with attribution and ordinary browser caching.

Verification: 22 Python tests passed; two map projection tests passed; JS syntax
checks passed. Browser tests covered typed number normalization, actual clicked
waypoints and an orbit, and a seven-command mission ending at home at zero
altitude. A real locally synthesized WAV transcribed correctly via HTTP. First
map-click testing exposed a 180-degree longitude offset; it was fixed and a
regression test added before completion. Optional model is downloaded to the
ignored models/speech directory. No microphone recording or live aircraft was
used. See docs/waypoint-planner.md for setup and limitations.

The local app is running at http://127.0.0.1:8766/planner/. Simulator work remains
separate. Mission upload/flight start are not implemented in the planner. Shared

# Custom gesture recognizer (trainable landmark classifier)

Completed: 2026-09-05 12:59:44 PM EDT (America/New_York)

## Prompt

"We need to build out a custom GestureRecognizer." User chose: a **landmark
classifier** (record hand landmarks, train a small model - no image dataset, no
TensorFlow), **custom takes priority with the canned recognizer as fallback**,
and a **collect / train / infer pipeline plus a config file** so gestures can be
defined later.

## What changed

- `src/landmark_features.py` (new) - `extract(landmarks, handedness)` turns the
  21 MediaPipe landmarks into a 63-d pose vector, normalized for translation,
  scale and handedness while keeping orientation. Versioned (`FEATURE_VERSION`).
- `src/gesture_model.py` (new) - `CustomGestureClassifier`: standardized k-NN
  vote loaded from `models/custom_gestures.npz`. Dependency-free (numpy only).
  Returns `(None, 0.0)` when not loaded, below the confidence threshold, or when
  the pose is outside a learned reject radius.
- `scripts/collect_gestures.py` (new) - webcam recorder: `--label NAME`, SPACE to
  record, `--list` for counts; appends pose vectors to `data/gestures/<label>.npy`.
- `scripts/train_gestures.py` (new) - reads `data/gestures/*.npy`, standardizes,
  reports 5-fold accuracy + a confusion matrix, computes the reject radius, and
  writes `models/custom_gestures.npz`.
- `src/hand_tracker.py` - now exposes `raw_landmarks` / `handedness`, loads the
  custom classifier, and overrides the canned gesture with a confident custom
  prediction. Added `gesture_source` ("custom" / "canned" / "none") to `HandState`.
- `src/gestures.py` - the action map is now `_DEFAULT_ACTION` merged over
  `config/gesture_actions.json` (keys starting with `_` ignored); added the
  `estop` action; `GestureState` carries `gesture_source`.
- `src/controls.py` - handle the `estop` event (immediate disarm).
- `src/visualizer.py` - HUD marks a custom gesture with `*` in green.
- `src/main.py` - passes `gesture_source` through; demo hand tags its source.
- `config/gesture_actions.json` (new) - the 7 defaults plus inline `_`-doc keys.
- `.gitignore` - ignore `data/` and `models/*` but keep
  `models/custom_gestures.npz` committable so a trained set travels with the repo.
- README - new "Custom gestures" section and layout-table rows.

## Verification

- `python -m py_compile src/*.py scripts/*.py` - clean.
- `landmark_features.extract`: confirmed translation-, scale-, and
  handedness-invariance on synthetic landmarks (63-d output).
- Synthetic 3-cluster dataset -> `train_gestures.py` reports 100% 5-fold accuracy,
  writes the npz; `CustomGestureClassifier` round-trips an in-distribution sample
  and returns `(None, 0.0)` for a random pose (reject radius working).
- `HandTracker` with the (synthetic) custom model loaded, on real MediaPipe hand
  images: all fell outside the reject radius and correctly **fell back to the
  canned gesture** (fist->Closed_Fist, victory->Victory, point->Pointing_Up),
  proving the priority + fallback path.
- `gestures.py` loads `config/gesture_actions.json` (7 mappings) and `estop`
  disarms in a controller test.
- Full `python src/main.py --demo --headless --duration 27` still completes the
  whole timeline and lands disarmed.
- Synthetic `data/` and the test `models/custom_gestures.npz` were deleted before
  commit; no real trained model ships yet.

Live webcam collection/inference not exercised here (no camera).

## Notes / limitations

- Installing scikit-learn pulled numpy back to 1.x and broke the opencv 5 / numpy
  2 combo; resolved by bumping `scipy>=1.13` and dropping the sklearn dependency
  entirely - the classifier is pure numpy, so `requirements.txt` is unchanged and
  teammates avoid the same cascade.
- k-NN keeps all samples in the npz; fine for hundreds-per-label, revisit if it
  grows large.
- The reject radius is a heuristic (3x the 90th-percentile intra-class NN
  distance); tune in `train_gestures.py` if custom gestures feel unresponsive or
  too trigger-happy.
- `src/flight_language.py` in the tree is a teammate's separate mission-planning
  work - left untouched, not staged.

# collect_gestures window closed instantly on a full label

Completed: 2026-09-05 05:05:46 PM EDT (America/New_York)

## Prompt

`collect_gestures.py --label two_flat` opens and auto-closes. Do I need to clear
the two_flat data?

## Cause

The auto-stop was `existing + len(rows) >= target`. Once a label already had
`--target` (250) samples, that was true on the first frame, so the window flashed
and exited. You do **not** need to clear anything - retraining uses whatever is
in `data/gestures/`.

## What changed - `scripts/collect_gestures.py`

- Auto-stop now triggers on **new samples this session** (`len(rows) >= target`),
  so re-running a label always lets you add more.
- HUD shows `new N/target   total M`.
- Tolerates initial failed `cap.read()` (camera warm-up) - only bails after 60
  consecutive failures instead of the first.
- New `--reset` flag deletes a label's `.npy` before recording (start that label
  over).
- Docstring clarified: each run appends; `--target` is per-run, not a cap.

## Verification

- `python -m py_compile scripts/collect_gestures.py` clean.
- `--list` path unchanged and working.
- Webcam loop not exercised here (no camera).

## For the task

No need to clear two_flat. Just record the new `other` class
(`python scripts/collect_gestures.py --label other`), then `train_gestures.py`.

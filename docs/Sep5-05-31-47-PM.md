# Training-free two-finger wiper; custom model made non-shadowing

Completed: 2026-09-05 05:31:47 PM EDT (America/New_York)

## Prompt

`--check-gestures` only recognized `two_up` / `two_flat` / one-finger poses - the
custom k-NN model was labelling every hand as one of its classes and overriding
the built-in gestures. Replace the custom-model wiper with a training-free
detector.

## What changed

- `src/finger_swing.py` (new) - `FingerSwingDetector`: reads the index+middle
  finger-line angle from the landmarks, tracks confirmed vertical/horizontal
  orientations, and fires `fly_east` / `fly_west` / `fly_north` when it sees
  `V -> H -> V -> H` within `WINDOW_SEC` (4 s) while a 2-finger pose is held.
  Purely geometric - never touches the MediaPipe gesture. `ENABLED` constant to
  turn it off. Also exports `resolve_pointed_direction()` (shared with
  `gestures.py`).
- `src/control_types.py` - `HandState.fingers` (5 bools: thumb..pinky extended).
- `src/hand_tracker.py`:
  - `_count_fingers` -> `_finger_states` returning the tuple; `fingers_up` is its
    sum.
  - `_CANNED_TRUST = 0.62`: when the built-in recognizer is at least this
    confident, the custom model is **not consulted at all** - a grabby custom
    model can no longer shadow a reliable built-in gesture.
- `src/gestures.py` - runs `FingerSwingDetector` each `update()`, folds its
  events in, shows `swing V>H>…` in the HUD hint; `_resolve_fly_pointed` now
  delegates to the shared helper.
- `config/gesture_sequences.json` - `__doc__` / `__example__` updated (wiper is
  no longer a combo).
- `tests/test_finger_swing.py` (new, 5) - right->east, left->west, half-swing
  no-op, needs two fingers, resets when the pose is lost.
- `tests/test_sequences.py` - `_Hand` stub gained `fingers`.
- `src/main.py` - demo does the wiper (`_DEMO_SWING` window, alternating
  vertical/horizontal 2-finger pose).
- README - "Fly where you point" section, layout row, `_CANNED_TRUST` note.

## Notes

- User should `del models\custom_gestures.npz` (or clear `data/gestures/`) to drop
  the grabby model entirely; the wiper no longer needs it. With
  `_CANNED_TRUST` in place, even leaving the model in place no longer breaks the
  confident built-ins.
- `fly_north` from the wiper is effectively unreachable (a real horizontal
  2-finger pose always resolves left/right); it stays as defensive code.
- Orientation thresholds (`_V_MAX_DEG` 35, `_H_MIN_DEG/MAX` 55/125) and timings
  are constants in `finger_swing.py` - loosen if the swing feels too strict.

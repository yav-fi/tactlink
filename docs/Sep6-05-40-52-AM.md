# MediaPipe on iPhone feasibility

Completed: 2026-09-06 05:40:52 EDT (America/New_York).

Request: Confirm whether Google MediaPipe can run on the phones.

Finding: Yes. Google's official iOS Gesture Recognizer supports Swift, camera livestream input, and a bundled model running on the device. The documented integration uses the MediaPipeTasksVision CocoaPod. The app can use the same compatible gesture_recognizer.task model as the Python detector. No Python runtime or PC inference is required.

Integration work: Add the native dependency and model resource, connect existing front-camera frames to the asynchronous recognizer, and stabilize the three command outputs. Pointing down needs explicit directional handling; adopting MediaPipe alone does not guarantee stable behavior or complete the requested command mapping.

Verification: Read https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer/ios and inspected the iOS project file inventory. No Podfile was found by the inventory search. This was a feasibility answer; no application changes, builds, or device deployments were performed.

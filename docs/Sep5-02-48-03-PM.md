# Drone collision checks

Completed: 2026-09-05 14:48:03 EDT (America/New_York).

Request: prevent drones flying through buildings and ground.

Added a shared Cesium geometry movement guard for manual flight, missions and playback. Uses a 20 m wide ray volume and 10 m clearance, excluding application entities, plus terrain ray/segment height checks. Manual batch movement is committed only if every member passes. Blocked playback is counted separately from arrival; the timer stops when all drones have arrived or been blocked. Deployment minimum is now 15 m.

Verification: 15 automated tests pass, including blocked manual/batch movement, mission cancellation, replay non-arrival and ground checks using deterministic geometry-query doubles. TypeScript and Vite production build pass. No live city collision/performance verification was performed.

Limitations: Cesium's private pickFromRay API sees rendered geometry only; unloaded/offscreen tiles and mesh holes cannot provide reliable collisions. Conservative footprint can stop short of narrow gaps. No automatic rerouting or drone-to-drone collision logic. GPU queries may affect large fleets.

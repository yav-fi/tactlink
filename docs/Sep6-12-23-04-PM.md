# Gesture demo: closed fist = hand off; fix the three-finger dash

Completed: 2026-09-06 12:23:04 PM EDT (America/New_York)

## Prompt

Make a closed fist do the random hand-off, and the three-finger pose still
wasn't moving the drone.

## What changed

- **Closed fist -> random hand-off.** `ACTIONS["Closed_Fist"] = "handoff_random"`
  with a ~0.7 s hold (`HOLDS`). It's one of MediaPipe's most reliable canned
  gestures, so the hand-off goes back through `GestureGate` instead of finger
  counting. Removed the two-fingers-up geometric hand-off and the canned-Victory
  promotion.
- **Three-finger dash fixed.** `hand_from_landmarks` extended-finger test loosened
  from `dist(tip) > dist(pip) * 1.02` to just `>` (tip farther from the wrist
  than the joint), and `classify_pose` now uses `up_count >= 3` instead of
  requiring exactly index+middle+ring with the pinky down - the ring/pinky
  detection was flickering and the pose never held. A canned command
  (`Open_Palm`, `Closed_Fist`, thumbs, ILY) short-circuits `classify_pose` so a
  flat hand still halts rather than reading as "3+ fingers -> dash forward".
- `classify_pose` remaining poses: `up_count >= 3` -> dash forward (any
  orientation); one/two fingers held sideways -> dash left/right.
- `CANNED` set swaps `Victory` for `Closed_Fist`; scripted `--demo` uses a
  `Closed_Fist` label for the hand-offs. HUD hint + docstrings updated.
- **`test_gesture_demo.py`** - closed-fist gate test, `classify_pose` updated,
  "a canned command is not re-read as a pose"; 15 tests.

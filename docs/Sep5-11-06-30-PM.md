# Gesture-controlled main 3D demo

Completed: Saturday, September 5, 2026 at 11:06:30 PM EDT (UTC-04:00).

## Prompt

Reconnect webcam hand gestures to the main application startup and Cesium simulation, remove the secondary camera-side drone rendering, start with one aircraft flying at the Washington Monument, and refresh the aircraft with a black/red look and red trail.

## What changed

- Added a headless webcam bridge that reuses the existing MediaPipe tracker and deliberate-hold gesture interpreter without opening an OpenCV window or rendering another simulation.
- Added a local gesture relay API with connection freshness, current pose/confidence/hold progress, and numbered command events.
- Updated `./start` to install the gesture extra when needed, launch the webcam bridge automatically, and stop it during normal cleanup.
- Added a compact gesture HUD to the main Cesium view and mapped takeoff/climb, land/return, orbit, halt, compass flight, forward flight, speed, and spin actions to the selected local drone.
- Added one default drone on the south side of the Washington Monument base plaza and launched it into a long orbit around the monument on page load.
- Switched local aircraft rendering to the bundled detailed UAV model, restyled its generated materials to metallic black with an emissive red nose/fin accent, and made its persistent and fading motion trails glow red.
- Extended orbit mission steps with an optional explicit center so the opening aircraft can circle the monument instead of its spawn point.
- Updated API and 3D controller tests for the new contracts and rendering.

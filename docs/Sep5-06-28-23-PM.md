# Three-finger "forward" + operator model

Completed: 2026-09-05 06:28:23 PM EDT (America/New_York)

## Prompt

Add a sideways three-finger gesture = "go forward". Confirmed direction: forward
is **relative to the operator who gestured**; move style: a fixed-distance dash;
responder: one shared drone (swarm stays an option). Context: the destination is
the model running on five phones carried by people walking around, any of whom
can command the drone.

## Confirmed understanding (repeated back to the user in chat)

Distributed multi-operator control - 5 walking people, each a phone/gesture

## What changed

- `src/operators.py` (new) - `Operator` (position, world-frame heading, random
  wander) and `OperatorPool(n)` (n people on a ring facing inward, one `active`,
  `resolve_forward_bearing()` = active operator's heading). Built for 5; used
  with `--operators 1` for now.
- `src/finger_swing.py` - `ThreeFingerForward`: index+middle+ring extended, held
  sideways (horizontal orientation) ~0.4 s -> emits `fly_forward`, once per hold.
- `src/gestures.py` - `GestureInterpreter` also runs `ThreeFingerForward`.
- `src/main.py` - `OperatorPool`, `--operators N`; each frame steps the pool and
  rewrites a `fly_forward` event to `fly_bearing:<active heading>`.
- `src/controls.py` - `fly_bearing:<radians>` maneuver: a dash along any world
  bearing (generalises the fixed `_COMPASS` dashes; shares the dash run logic).
- `src/visualizer.py` - `render(..., operators=)` draws each operator as a
  standing figure + heading arrow + name; the active one in cyan.
- `tests/test_operators.py` (new, 4), `test_finger_swing.py` +3 (three-finger
  fires forward once / not vertical / not two fingers), `test_fly_maneuver.py`
  +1 (`fly_bearing` dashes along the given angle).
- README - gesture table row, new "Operators" section, `--operators`, layout row.

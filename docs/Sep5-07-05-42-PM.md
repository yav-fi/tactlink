# Three-finger detector - loosen + add a debug readout

Completed: 2026-09-05 07:05:42 PM EDT (America/New_York)

## Prompt

The three-finger "forward" gesture isn't recognised on the real webcam. (It is
geometric, not trained - no training needed - but the detection was too strict.)

## What changed

- `src/hand_tracker.py` `_finger_states` - rewritten to an **angle-based** test:
  a finger counts as extended when its mcp->pip and pip->tip segments point the
  same way (cos > 0.35, i.e. not curled back) and the tip is past the pip. This
  is far more reliable for a hand held sideways than the old
  distance-from-wrist ratios, which flagged curled short fingers as extended.
  Verified on MediaPipe sample stills: fist 0, point 1, victory ~3 (thumb),
  open hand 5.
- `src/finger_swing.py`:
  - `_three_fingers` now wants **index+middle+ring up and thumb tucked** (pinky
    ignored - it follows the ring finger); was "pinky must be down".
  - new `_is_sideways()` with `_THREE_MIN_H_DEG = 42` (was the 55-125 "H" band);
    hold + release times 0.4 -> 0.35 s.
- `src/main.py` `_gesture_check_panel` - shows `fingers TIMRP` (which fingers the
  tracker thinks are extended) and `orient V/H/?` so a live pose can be debugged.

## Verification

- `python -m py_compile src/*.py tests/*.py` clean; all suites green
  (operators 5, finger_swing 8, fly_maneuver 10, swarm 5, sequences 10).
- `--demo --check-gestures` still logs the scripted `fly_bearing:0.0000` from the
  three-finger window.
- Real-webcam three-finger recognition still unverified here (no camera) - the

## Notes for the user

- Run `python src/main.py --check-gestures`, hold index+middle+ring sideways, and
  read the `fingers` / `orient` line. Want `fingers -IMR-` (or `-IMRP`) and
  `orient H`, then `fly_bearing:...` in the log.
- A **custom model is still loaded** (`models/custom_gestures.npz`: `1-finger`,
  `two_up`, `two_flat`, no `other` class). Detection is geometric now, so that
  model is unnecessary and could shadow `Pointing_Up`; recommend
  `del models\custom_gestures.npz`.
- Tuning knobs are all at the top of `finger_swing.py`.

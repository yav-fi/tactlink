# Thumbs for arm/land + recognition robustness

Completed: 2026-09-05 04:23:59 PM EDT (America/New_York)

## Prompt

Recognition of open-palm / closed-fist / pointing is finicky. Make 👍 Thumb up
arm + take off and 👎 Thumb down disarm + land.

## What changed

- `config/gesture_actions.json` - `Thumb_Up` → `takeoff`, `Thumb_Down` → `land`;
  `Open_Palm`, `Closed_Fist`, `Victory` set to `null` (no standalone action - they
  remain combo ingredients). `_load_actions()` now honours `null` / `"none"` /
  `"off"` to disable a default gesture.
- `src/gestures.py`:
  - `_DEFAULT_ACTION` rewritten to the new intent (thumbs = takeoff/land,
    `Pointing_Up` = orbit, `ILoveYou` = return_home).
  - `GestureInterpreter(..., actions=)` so tests can supply their own map instead
    of depending on the shipped config.
  - Likely cause of the "finicky" feel: `Open_Palm` / `Closed_Fist` were combo
    members, so their single command was held back `single_delay` + `COMBO_GRACE`
    (~1.5 s). `Thumb_Up` / `Thumb_Down` are not in any pattern, so takeoff/land
    now fire at `HOLD_SEC` (~0.4 s).
- `src/hand_tracker.py` - `_GESTURE_MIN_SCORE = 0.55`: a canned gesture below that
  confidence is treated as "None", cutting flickery misreads.
- `src/visualizer.py` - HUD hint updated for the new mapping.
- `src/main.py` - demo timeline switched to `Thumb_Up` / `Thumb_Down` for
  takeoff/land.
- `tests/test_sequences.py` - mechanism tests use an explicit `ACTIONS` map;
  added `test_shipped_action_config` (Thumb_Up=takeoff, Open_Palm disabled).
- README - gesture table, confidence-floor / null-disable note.

Live webcam not exercised (no camera); the confidence floor is only visible with
a real feed.

## Notes / limitations

- The `[Open_Palm, Closed_Fist, Open_Palm]` return-home combo is unchanged and
  still uses the poses the user finds finicky. 🤟 `ILoveYou` is a reliable
  single-gesture path to the same `return_home`; the combo could be dropped or
  re-patterned onto thumbs/point if it keeps misfiring.
- `_GESTURE_MIN_SCORE` (0.55) is a guess - raise it if wrong gestures still slip
  through, lower it if correct poses get dropped.
- `Victory` / thumbs-as-speed are gone; with hand flight off there was nothing
  for them to do anyway.

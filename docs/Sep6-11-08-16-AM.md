# Gesture demo: add the wiper dash and point-to-hand-off

Completed: 2026-09-06 11:08:16 AM EDT (America/New_York)

## Prompt

In `demos/gesture-handoff/`: add the two-finger "wiper" (vertical<->horizontal
swing) that dashes the drone left/right, and bring back point-at-an-operator as
a hand-off option alongside the Victory-hold random hand-off.

## What changed

- **`gestures.py`**
  - `Hand` dataclass + `hand_from_landmarks(pts)` — 21 landmarks -> finger
    extension states + index/middle pointing vector.
  - `FingerSwingDetector` (ported from `src/finger_swing.py`) — index+middle held
    out, orientation V->H->V->H within 4 s -> `dash_east` / `dash_west` the way
    the fingers point. `.active` (mid-swing) and `.progress` for the HUD.
  - `ACTIONS["Victory"]` renamed `handoff` -> `handoff_random`.
- **`flight.py`**
  - `Operators`: `aim_from_point(point_dir, drone_xy)` (direction -> operator),
    `aim` / `aim_progress` / `commit_aim` (dwell-to-send). `random_handoff` kept.
  - `Autopilot`: `dash_east` / `dash_west` (nudge ~5 m sideways, then hold at the
    spot - no spring-back), `handoff_aim` (targeted), `handoff_random` (Victory).
    New `dash` mode in `update`.
- **`gesture_demo.py`**
  - `Sim.advance(raw_label, hand, dt, now, force_aim=None)` now runs the swing
    detector and the point-aim dwell. A transient Victory read is ignored while a
    swing is in progress. `run_live` builds a `Hand` from the landmarks and
    passes it; the scripted `--demo` drives dash/aim through timeline markers.
  - HUD gains the aim ring fill and a `wiper V>H>..` indicator.
- **`scene.py`** — orange target ring on the aimed operator, filling as you hold;
  aim / wiper HUD lines; updated bottom hint.
- **`test_gesture_demo.py`** — 14 tests (was 11): wiper full/partial/one-finger,
  dash distance + hold, point-aim selection + dwell + commit, landmark parsing.
- README updated.

## Notes

- Overlapping 2-finger gestures resolved by motion vs. hold: a *swinging*
  2-finger point is the wiper; a *steady* sideways point (>= 1.4 s) is a targeted
  hand-off; a steady point *up* is orbit (canned `Pointing_Up`). Point-aim is
  suppressed while `FingerSwingDetector.active`.

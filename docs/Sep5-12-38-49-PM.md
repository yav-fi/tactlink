# Monument orbit camera

**Completed:** 2026-09-05 12:38:49 EDT (America/New_York)

## Prompt

Fix the camera so the real 3D map can be rotated to inspect the back of the Washington Monument.

## What changed

- Added an explicit Orbit monument camera mode centered on the Washington Monument's geographic coordinate.
- In orbit mode, left-drag rotates around the monument and the mouse wheel changes the camera distance. This makes all sides of the photorealistic 3D mesh inspectable.
- Preserved free-flight mode as a separate camera mode, with its existing keyboard movement controls.

## Verification

- Ran `npm run build` from `3d-mapping` successfully, including TypeScript checking and Vite's production build.

## Notes

The Google Photorealistic 3D Tiles dataset must be enabled through a Cesium ion token for the real-world 3D mesh to render. The fallback globe does not contain a 3D Washington Monument model.

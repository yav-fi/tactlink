# Explain gesture instability

Completed: 2026-09-06T05:31:09.516352-04:00 (EDT), America/New_York.

Prompt: Explain the current gesture-detection approach and why labels flicker during the physical demo.

Findings from current source: The front-camera capture pipeline runs Apple Vision VNDetectHumanHandPoseRequest locally, selecting one hand and throttling processing to at most 15 frames/second. makePose requires 16 selected joints above 0.35 confidence. Overall pose confidence is the minimum of wrist and five fingertips; guards use 0.45, then publication uses 0.55. Handwritten two-dimensional distance ratios decide which fingers are extended, and combinations map to labels. Thumbs-up/down also uses a fixed normalized-image vertical separation threshold of 0.12. Each ordinary frame publishes a new label or None with no landmark smoothing, label voting, or separate entry/exit thresholds. The dynamic finger-swing sequence has its own small history but does not stabilize ordinary poses.

The phone streams its latest result at about 10 Hz. The browser requires confidence >=0.65, maps weaker samples to None, and requires an uninterrupted 0.4-second hold. A sampled label change restarts ordinary control holds. Fist follow persists through None, but another supported command label from the followed person exits follow immediately. Thus a brief misclassification can cancel follow without deliberate user intent. Main identified weaknesses are brittle joint rejection, raw per-frame thresholds, repeated differing confidence gates, and missing temporal stabilization. These are code-based explanations, not a measured per-frame diagnosis of this particular user's hand.

Explained proposed improvements: stabilize landmark/finger estimates, confirm new labels over several frames, tolerate brief uncertain detections while retaining prompt deliberate stop behavior, and confirm exit/handoff events rather than acting on one noisy classification. No application code, thresholds, or device builds changed because the user requested an explanation. Verification was source inspection; no tests were necessary.

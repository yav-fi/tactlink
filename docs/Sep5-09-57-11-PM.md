# Prompt work completed September 5, 2026 at 9:57:11 PM EDT (UTC-04:00)

## Prompt

Let plain-language commands target real places such as the Washington Monument, support relative forward/back/left/right movement and timed waits, and string those actions together into one mission that runs automatically on the selected drone.

## Summary

The slim command line now resolves named DC landmarks and compiles multi-part phrases into the existing ordered browser mission format. Place travel, timed hover, relative movement, turns, orbit, and return-home steps run sequentially on the selected drone.

## Changes

- Added a built-in catalog of safe approach coordinates beside eight major Washington, DC landmarks.
- Added Cesium ion Google place lookup for other named DC destinations when an ion token is configured.
- Added parsing for `go/fly/send to <place>`, `go forward/back/left/right`, `turn left/right`, and `wait [for] N seconds`.
- Added sequence splitting for `then`, `and then`, action-oriented `and`, and action-separating commas.
- Added a mission-sequence compiler that preserves order, calculates cumulative geographic positions, follows the drone's current heading, updates heading after destination legs, and emits timed hover steps.
- Routed single and chained flight phrases through one local mission rather than executing disconnected UI actions.
- Updated help text, slash-command guidance, documentation, and focused tests.

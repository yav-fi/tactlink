# Orbit gesture + gestures-only control

Completed: 2026-09-05 04:13:11 PM EDT (America/New_York)

## Prompt

1. Change ☝️ `Pointing_Up` so the drone flies out to a 10 m radius from the
   origin and then circles the origin continuously.
2. Turn off the palm-position / tilt / pinch continuous control - the drone
   should move only from finger gestures.

## What changed

- `src/controls.py`:
  - `HAND_FLIGHT_ENABLED = False` (module constant). When off, `update()` skips
    `_fly()` entirely; an armed drone with no active routine hovers
    (`ControlInput(armed=...)`, all axes zero). Set it `True` to restore
    palm/tilt/pinch flying.
  - New `orbit` maneuver: flies to `_ORBIT_RADIUS` (10 m) with a radial P term,
    then holds a `_ORBIT_SPEED` (3 m/s) tangential velocity (counter-clockwise)
    around the origin, holding entry altitude and nosing along the direction of
    travel. It never self-clears - it runs until another command maneuver starts
    or the gesture fires again (toggle off -> hover).
  - Added `_world_to_body()` helper; `return_home` / dash / orbit now share it.
- `config/gesture_actions.json` - `"Pointing_Up": "orbit"` (was `spin360`;
  `spin360` is still a valid action, just unmapped). Updated `__doc__`.
- `src/visualizer.py` - HUD shows `MODE HOLD` (not a flight-mode name) and hides
  the `SPEED` line when hand flight is off; hint line rewritten for gestures-only.
- `src/main.py` - demo timeline comment (`Pointing_Up` -> orbit).
- `tests/test_fly_maneuver.py` - `test_orbit_converges_to_ring_and_keeps_circling`,
  `test_orbit_repeat_gesture_stops`.
- README - "Control model" section, gesture table, actions list.

## Notes / limitations

- With hand flight off, `cycle_mode` (Victory) and `speed_up` / `speed_down`
  (thumbs) are no-ops. Consider remapping those three gestures - they are free
  slots now (`config/gesture_actions.json`).
- Orbit is counter-clockwise, fixed 10 m / 3 m/s. Direction/radius/speed are
  constants in `controls.py` (`_ORBIT_RADIUS`, `_ORBIT_SPEED`); a clockwise
  option or a config knob is a small follow-up.
- Orbit holds ~10.2 m (2 % steady-state offset from the P-only radius term).
- Exits: point again, or `land` / `return_home` / `estop` / a `fly_*` dash / a
  new `takeoff`. There is no "hand back to manual" exit while hand flight is off.
- Demo-only: `orbit` moves the simulated drone, no `mission:` command.

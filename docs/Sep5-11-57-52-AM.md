# One-command ask script

Completed: 2026-09-05 11:57:52 AM EDT

## Prompt

Give a single, ollama-`run`-style command that starts the inference engine if it isn't
already running and asks it a question in one shot.

## What changed

- Added `scripts/ask.sh`: checks `GET /health` on the chat server; if it's not up,
  launches `start_chat_server.sh` in the background and polls until healthy, then sends
  the given question through `chat_client.chat_sync` and prints the reply. Works from
  any working directory (sets `PYTHONPATH` to the project root so `chat_client` imports
  correctly regardless of cwd).

## Verification

- Ran it against an already-running server (warm path): got a correct answer to
  "what's 17 * 23?" (391), invoked from `/tmp` to confirm cwd-independence.
- Killed the server and re-ran it (cold path): it detected the server was down,
  auto-started it, polled until healthy, and answered "name one moon of jupiter"
  correctly — total wall time ~15s including model load.

## Notes, assumptions, limitations

- Leaves the server running after answering (matches Ollama's own behavior of keeping
  a model resident after `ollama run`), rather than starting-then-stopping per question.
- No thermal gating was applied here — this is a correctness/functionality check, not a
  timed benchmark, per this machine's own GPU-timing discipline (gating is reserved for
  comparable timing measurements).

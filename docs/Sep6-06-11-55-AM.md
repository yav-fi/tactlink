# Confirm pretrained model in use

Completed: 2026-09-06 06:11:55 EDT (America/New_York).

Request: Confirm whether Google's pretrained model can be used now and whether it is already used.

Yes: the installed iPhone app uses Google's stock MediaPipe GestureRecognizer model, the same base model as the repository's PC recognition paths. It does not use Ian's optional custom NPZ. The phone's final labels also pass through custom directional/three-finger/swing rules and temporal filtering; those rules can override raw learned predictions. Therefore current poor output cannot be attributed solely to the pretrained classifier without separating those stages. Google does not provide a built-in Pointing_Down category, so that requested command needs additional directional handling.

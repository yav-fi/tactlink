# Add the gesture hand-off demo to the repo

Completed: 2026-09-06 10:33:03 AM EDT (America/New_York)

## Prompt

Bring the standalone webcam "drone hand-off" demo into the repo so it runs from
`main`, and fix the Victory-sign hand-off, which never triggered live.

## What changed

- **`demos/gesture-handoff/`** (new) — a self-contained demo, 5 modules:
  - `gesture_demo.py` — webcam loop, MediaPipe `GestureRecognizer` (VIDEO mode),
    `--demo` scripted flight, `--check`, `--headless --out` frame render, side by
    side webcam + 3D scene compositing.
  - `gestures.py` — `GestureGate`, a hold-to-fire debounce.
  - `flight.py` — `Quad` (first-order physics), `Operators` (N people scattered
    at random through the scene, one holds the drone), `Autopilot`
    (idle / climb / land / orbit / return / handoff / halt; nose tracks the
    nearest operator).
  - `scene.py` — hand-rolled pinhole 3D render (grid, standing-figure operators,
    drone, HUD).
  - `test_gesture_demo.py` — 11 unit tests.
  - `README.md`.
  It imports nothing from `src/` and runs on the repo's existing deps
  (mediapipe 1.x / opencv 5 / numpy 2 — verified).
- **Victory hand-off fix.** `GestureGate` now tolerates recognizer dropouts: a
  gap shorter than `GAP_SEC` (0.45 s) does not reset the hold, so a multi-second
  hold actually completes. Before, any single frame where MediaPipe lost the
  pose reset the 3 s timer to zero and it never fired. Victory hold lowered
  3 s -> 2 s; `_fired` is only cleared once the pose has been absent for the full
  gap (prevents a double-fire on a flicker after firing).
- Hand-off is **random**: holding Victory sends the drone to a random *other*
  operator (`Operators.random_handoff`), no aiming.
- `--threshold` default 0.65 -> 0.5, and the webcam panel now shows the raw
  below-threshold guess (`Victory? 42%`) so a near-miss is visible.
- Operators are scattered uniformly in a disc around the origin each run (min
  ~2.4 m apart), not lined up on the axes.
- **`.gitignore`** — ignore the demo's downloaded model, `*.download`, and
  `__pycache__/`.

## Changes

- Replaced Apple Vision joint detection and handwritten canned classification with MediaPipeTasksVision 0.10.21. Bundles the exact float16 v1 GestureRecognizer model referenced in src/hand_tracker.py. The setup script downloads it with a pinned SHA-256; Pods and model binaries are ignored in Git.
- Added the CocoaPods workspace, lockfile, model resource, reproducible setup command, and workspace-aware signing/deployment. The selected Xcode 26.3 lacks its downloadable iOS platform; the deployment script successfully falls back to the fully installed Xcode 16.4 on this Mac.
- Uses one hand, the PC's video-mode tracker and confidence settings, a serial background camera queue capped at 15 FPS, BGRA portrait frames, and strictly increasing timestamps. Camera frames remain local.
- Preserved learned fist, palm, thumb up/down, Victory, and ILoveYou classes. Ported the PC's angle-based finger extension test for three-finger forward and V-H-V-H directional swings. Added explicit index pointing up/down; horizontal pointing is neutral. The old phone-demo pointing-up orbit action now climbs, per the user's requested mapping.
- Recent-frame voting stabilizes output. Missing hands clear stable output after 180 ms; interruptions/errors clear pending gestures. Custom landmark-derived signs use an acceptance score of 0.8, not a learned class probability. Optional PC custom k-nearest-neighbor models were not ported because no trained model artifact was present in this checkout.
- A fist caller retains command ownership through later altitude commands; proximity cannot silently take control back. Palm, a new fist, or signal loss releases/transfers the claim. Altitude commands leave follow; release then holds the resulting altitude.
- Portrait preview rotation now runs after the capture session starts, during layout, and on SwiftUI updates. This addresses the late-created preview connection. Added clearer in-app and browser instructions.

# collect_gestures usage hint

Completed: 2026-09-05 04:48:54 PM EDT (America/New_York)

## Prompt

Running `collect_gestures.py` printed "no samples yet in data/gestures" and did
nothing.

## Cause

The script only opens the webcam recorder when given `--label`. Run with no
arguments (e.g. the IDE Run button) it falls through to the list/usage path. Not
a bug - it needs `python scripts/collect_gestures.py --label <name>` from a
terminal.

## What changed

- `scripts/collect_gestures.py` - the no-`--label` path now prints an explicit
  example command instead of just the empty-list message.

## Verification

- `python -m py_compile scripts/collect_gestures.py` clean.
- `python scripts/collect_gestures.py` (no args) now prints the usage example.

## Notes

# Gesture demo: finger-counted hand off + three-finger dash forward

Completed: 2026-09-06 12:14:11 PM EDT (America/New_York)

## Prompt

Victory still doesn't fire live, and there's no three-finger dash-forward.

## Approach

MediaPipe's "Victory" classifier is what's failing for the user (take-off /
land / halt / orbit / return use the same recogniser and work). So the hand-off
and the dashes now come from **counting extended fingers** in the landmarks
instead of a canned label.

## What changed

- **`gestures.py`**
  - Removed `SidePointDash`. `ACTIONS` drops `Victory` (the gate now only maps
    Thumb_Up/Down, Open_Palm, Pointing_Up, ILoveYou).
  - `Hand.up_count` = index..pinky extended count.
  - `classify_pose(hand, canned)` -> a held-pose command from finger geometry:
    two fingers up = `handoff_random`, three fingers = `dash_forward`, one/two
    fingers held sideways = `dash_east` / `dash_west`. A canned `"Victory"` is
    still accepted as the hand-off pose (belt and suspenders).
  - `HeldPose` - fires a pose command once after its hold (hand off 1.0 s, dash
    forward 0.55 s, side dash 0.5 s), dropout-tolerant, needs a release to repeat.
- **`flight.py`** - `Autopilot` gains `dash_forward` (nudge +y, away from the
  camera); the three dash commands share one branch.
- **`gesture_demo.py`** - `Sim.advance` runs `classify_pose` + `HeldPose`;
  `--diag` and the always-on webcam readout now also print the classified pose
  (`fingers -IMR-  -> dash_forward`). Scripted `--demo` drives poses via a
  `force_pose` timeline entry.
- **`scene.py`** - pose hold-progress bar + label; updated hint.
- **`test_gesture_demo.py`** - `ClassifyPoseTests` + `HeldPoseTests` +
  `dash_forward` flight test; 14 tests.
- README updated.

## Verification

- `python -m unittest` (folder) - 14 pass, incl. every finger count -> command,
  that point-up stays "not a pose", canned Victory promotes, hold + release +
  dropout behaviour, and `dash_forward` moves +y then holds.
- `--check` loads the model; `--demo --headless` plays the full sequence
  (dash right / left / forward, two hand-offs, orbit, return, land).
- Live webcam still not testable here - the always-on readout + `--diag` show the
  finger states and classified pose so any remaining mis-count is visible and
  the `1.02` extended-ratio in `hand_from_landmarks` can be tuned.

# Gesture demo: fist hand-off is now finger-counted, not MediaPipe

Completed: 2026-09-06 12:31:42 PM EDT (America/New_York)

## Prompt

The demo doesn't even recognise a closed fist.

## What changed

MediaPipe's "Closed_Fist" label was still going through `GestureGate`. Moved it
to the geometric path like the dashes, so the model's classifier is out of the
loop for everything except the five reliable gestures.

- **`gestures.py`**
  - `ACTIONS` = only Thumb_Up/Down, Open_Palm, Pointing_Up, ILoveYou.
  - `classify_pose`: `up_count == 0` (all four fingers curled) -> `handoff_random`
    (0.5 s hold via `HeldPose`); `up_count >= 3` -> dash forward; 1-2 fingers held
    sideways -> dash L/R.
  - `_CANNED_COMMANDS` (short-circuits `classify_pose`) = the five gate gestures
    + `Pointing_Up`; `Closed_Fist` removed so a fist is read geometrically even
    when the model doesn't label it.
- **`gesture_demo.py`**
  - Gesture recogniser options: `min_hand_detection_confidence` /
    `min_hand_presence_confidence` / `min_tracking_confidence` = 0.3 (a fist is
    harder for the hand landmarker than an open palm).
  - Webcam panel readout is now a full-width green banner at the top, shows the
    extended-finger string + count (`-IMR- (3 up)`), the classified pose, or
    `no hand detected`. `--diag` prints the same each frame.
  - Scripted `--demo` drives the hand-offs with `force_pose='handoff_random'`.
- **`test_gesture_demo.py`** - fist -> `handoff_random`, Victory + Closed_Fist do
  nothing in the gate; 14 tests.

## Verification

# Restore landmark-driven browser gestures

Completed: September 6, 2026 at 1:39:30 AM EDT (UTC-04:00)

## Prompt

Investigate why the README's pointing-motion gesture and three-finger W-like
gesture were missing from the main Cesium application, and restore them.

## What changed

- Identified that both gestures still existed in `src/finger_swing.py`, but the
  browser migration had only carried over MediaPipe's canned category label and
  had not carried over the landmark-driven geometry detectors.
- Ported the original orientation-independent finger-extension checks,
  two-finger point direction, V-H-V-H timing window, dropout reset, and
  three-finger hold/release behavior to TypeScript.
- Connected the detector directly to the 21 landmarks already returned by the
  hidden browser MediaPipe recognizer.
- Restored the three-finger forward dash and the two-finger pointing dash to the
  selected drone without changing any existing static hand-signal mappings.
- Added live HUD hints for the W-pose hold and confirmed V/H wiper stages.
- Updated both README files to make clear that these controls are available in
  the main browser/Cesium demo.

## Notes

The browser mirrors landmark x-direction to match the legacy Python webcam,
which flipped frames before recognition. Consequently, pointing to the
operator's right remains an east dash and pointing left remains a west dash.
Live recognition still requires an interactive browser and camera.

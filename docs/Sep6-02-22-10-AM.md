# Complete iPhone gesture-to-simulator integration

- Completed: 2026-09-06 02:22:10 AM EDT (-0400)
- Prompt: Complete the three-iPhone position, facing, and on-device hand-gesture bridge to the Python drone simulator while preserving nearest-operator control and keeping the system simulation-only.

## Summary

Added dependency-free, on-device hand recognition using Apple's Vision hand-pose landmarks and the front camera. Each phone now sends a bounded gesture label, confidence, and source through the existing UDP bridge. The simulator preserves stable per-phone operators and gesture interpreters, accepts geometric left/right/forward labels, and resolves those directions relative to the nearest controlling operator's compass facing.

## Changes

- Added `GestureCamera.swift` with permission handling, foreground/background lifecycle, 15 fps capture, confidence rejection, mirrored portrait input, common gesture classification, V-H-V-H two-finger dash detection, and three-finger forward detection.
- Added a live gesture/status/confidence indicator to the joined-room screen.
- Extended RoomBridge and PhoneFeed with `gestureConfidence` and `gestureSource`; no images leave the phone.
- Added `Dash_Left`, `Dash_Right`, and `Three_Finger_Forward` mappings and operator-relative bearing resolution.
- Expanded the three-phone mock script to exercise takeoff, orbit, both lateral dashes, forward, return-home, halt, and land.
- Added focused Swift geometry tests and Python parsing, ownership, and direction tests.
- Updated iOS and handoff documentation and made deployment use the active `xcode-select` path.

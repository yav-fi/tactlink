# Proximity control + follow-nearest + emergent handoff

Completed: 2026-09-05 06:40:24 PM EDT (America/New_York)

## Prompt

Refined concept: N people each with a **chest-mounted phone**, all in the
visualizer; the drone flies **above** them; operators flash hand signs to their
chest camera to command it; **the drone obeys the operator nearest to it**, and
directional gestures let an operator send the drone toward someone else (handoff).
Confirmed: handoff = "point + fly that way" (emergent from proximity, no dedicated
gesture); gesture source stays the single webcam for now (phones stream later);
idle drone **follows** the nearest operator.

## What changed

- `src/operators.py` - `OperatorPool.set_active_by_proximity(xy)`: control goes
  to the operator with the smallest horizontal distance to the drone.
- `src/control_types.py` - `GestureState.follow_pos` (an (x, y) the idle drone
  trails).
- `src/controls.py`:
  - `_follow_point(state, xy)` - easy-going P-track toward a ground point while
    holding altitude; used as the idle behaviour when armed and `follow_pos` is
    set (was: hold position).
  - `_TAKEOFF_ALT` 1.3 -> 3.0 m so the drone sits above people.
- `src/main.py` - each frame: `set_active_by_proximity(leader xy)` then
  `gstate.follow_pos = active operator pos`. `--operators` defaults to >=4 in
  `--demo`, where the operators are lined up 6 m apart facing east (deterministic
  handoff).
- `src/visualizer.py` - `CTRL opN` in the HUD (multi-operator only).
- Tests: `test_operators` +1 (nearest-operator), `test_fly_maneuver` +1
  (idle-follow), `test_swarm` altitude asserts use `_TAKEOFF_ALT`.
- README - rewritten "Operators" section, takeoff-altitude note.

## Notes / next

- Single webcam still drives whoever currently has control (you "become" each
  operator). Real per-phone gesture streams + phone position data is the next
  milestone - `set_active_by_proximity` and `follow_pos` are the seams.
- Follower drones in a swarm trail the leader, which trails the operator, so the
  whole formation follows.
- Handoff needs the controlling operator to be facing the target person (chest
  camera); in the sim the demo lines them up, live it is the operator turning
  their body.

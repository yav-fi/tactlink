# "Fly where I point" wiper combo

Completed: 2026-09-05 04:00:47 PM EDT (America/New_York)

## Prompt

Add a gesture: a spread ✌️ V rotated vertical → horizontal → vertical → horizontal
(a double wiper), triggering the drone to fly in the direction the fingers point;
if the direction can't be read, fly north. No sweep/motion detection for now.

Confirmed design: world-absolute compass, bounded ~5 m dash then hover, direction
from the final flat pose (left/right → west/east, else north), up pose = canned
`Victory`, requires the drone armed, demo-only (no mission runtime).

## What changed

- `src/control_types.py` - `HandState.point_dir`: index+middle pointing vector
  (image space, x right / y down).
- `src/hand_tracker.py` - computes `point_dir` from landmarks (5→8) + (9→12).
- `src/gestures.py`:
  - `GestureInterpreter.update(..., hand=None)` stores the latest `point_dir`;
  - a combo whose action is `fly_pointed` is resolved at fire time by
    `_resolve_fly_pointed()` → `fly_east` / `fly_west` / `fly_north`
    (`|dx| ≥ 0.55` and horizontal-dominant → east/west, else north).
- `src/controls.py` - new autopilot maneuvers `fly_north/south/east/west`:
  world-frame compass dash (`_COMPASS`), bounded to `_DASH_DISTANCE` (5 m) with
  an ease-out, holds the entry altitude (min 1.3 m), requires armed, HUD shows
  `MODE FLY_EAST`.
- `config/gesture_sequences.json` - added
  `["Victory", "v_flat", "Victory", "v_flat"]`, window 5.0 s → `fly_pointed`.
- `src/main.py` - `_demo_hand` emits the wiper (with a horizontal `point_dir`)
  and passes `hand=` into the interpreter; demo timeline runs the wiper ~t=22-26.
- `tests/test_sequences.py` - `test_wiper_combo_resolves_fly_direction`
  (right→east, left→west, up→north; Victory poses don't cycle mode).
- `tests/test_fly_maneuver.py` (new) - dash direction, bounded distance,
  altitude hold, ignored-when-disarmed.
- README - actions list, combos section, the wiper explanation.

## Notes / limitations

- **`v_flat` is not trained yet.** The combo is shipped in the config but cannot
  fire until you run `python scripts/collect_gestures.py --label v_flat` (spread
  V held horizontal, ~200 samples) and `python scripts/train_gestures.py`.
- Because `Victory` is now a combo member, a lone `Victory` (cycle mode) picks up
  the ~1-1.5 s single-gesture hold/cancel delay.
- Direction is world-absolute (north = sim +y). Only left/right is reliable from
  a horizontal V; vertical / toward-camera / angled all fall back to north.
- No sweep verification - snapping between the two poses still counts. A
  `MotionGesture` primitive (finger-line angle over time) is the follow-up if
  posed endpoints without motion become a problem.
- Demo-only: `fly_*` moves the simulated drone, it does not emit a `mission:`
  command.

The precise failed gesture was not captured live, but code inspection found three relevant failure paths: the Mac required 0.65 confidence while the phone displayed fists at 0.55; any incorrect frame discarded the pending hold; and one other action label canceled follow immediately.

Aligned fist acceptance with the phone's 0.55 threshold. Other gesture thresholds remain unchanged. Fired claims stay latched through brief flicker, preventing a previous target's continuously held fist from stealing back control. A release lasting 250 ms rearms that gesture.

Follow now survives a single alternate gesture label. A different command must be held for 400 ms before replacing follow, and that command comes from the followed person. Missing or stale target positions still stop follow. Added per-phone received label, confidence, and pending fist claim percentage to the visualizer.

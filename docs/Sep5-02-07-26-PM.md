# Synchronized recorded-path playback

Completed: 2026-09-05 14:07:26 EDT (America/New_York).

Request: on the new 3d-mapping-2 branch, launch all drones as prisms through their recorded paths at assigned speeds with an elapsed timer until all arrive.

Confirmed current branch is 3d-mapping-2. Added Run all paths, Stop playback, elapsed seconds and arrived count. Playback snapshots each recorded route and speed, starts every prism at route distance zero, and advances along cumulative 3D segment lengths using one real-time clock. The timer freezes at the exact longest route duration, even after a delayed frame. Routes and release markers remain unchanged across replays. Empty/stationary routes are skipped; new deployment and speed/route edits are disabled while playing. Stopping restores editing, and Reset all removes playback entities. Playback currently consumes recorded trails, not unflown text preview geometry.

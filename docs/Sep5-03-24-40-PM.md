## Notes

- This run used an Apple M4 MacBook Pro with 16 GB of memory. The older 125.9 tok/s
  entry is retained because it was measured on different M3 Max / 48 GB hardware.
- The 9B draft is DFlash v1 and exposes no DFlash2 candidate-selector confidence
  signal, so LibraSpec is correctly disabled for this pairing.
- `benchmark_result.json` is intentionally ignored and contains the latest full local
  result, including the same receipt and model identity.

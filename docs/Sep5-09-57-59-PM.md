# Simulator bottom HUD and cleaner markers

Completed Saturday, September 5, 2026 at 9:57:59 PM EDT (UTC-0400).

## Prompt

Remove the visible boxes around simulator start/release markers, move simulator information into a full-width bottom bar with longitude, latitude, and other useful stats, and make AI mission compilation a little faster if possible.

## Changes

- Replaced the 3D start and release prisms with unobtrusive, outlined text labels.
- Expanded the local command dock into an edge-to-edge bottom bar.
- Added live selected-drone telemetry for drone ID, latitude, longitude, altitude, configured speed, flight state, and fleet count.
- Throttled DOM telemetry refreshes to 10 Hz while leaving simulation and camera updates at display rate.
- Reduced the local mission compiler's maximum generated response from 900 to 640 tokens to shorten worst-case AI response time while retaining room for multi-objective mission JSON.
- Updated simulator tests and documentation for label-only markers and the bottom HUD.

# Python and iPhone gesture comparison

Completed: 2026-09-06 05:37:55 EDT (America/New_York).

## Request

Compare Ian's earlier Python PC gesture detection with the current iPhone implementation, in the context of simplifying controls to fist to call, point up to climb, and point down to descend.

## Findings

- Python `src/hand_tracker.py` uses MediaPipe GestureRecognizer: learned gesture categories plus 21 hand landmarks. It accepts a top gesture score of at least 0.55 and optionally falls back to a custom landmark classifier below 0.62. No root `models/` directory exists in this checkout, so a previously trained custom model used on Ian's machine cannot be confirmed here.
- iPhone `ios/SignalMap/GestureCamera.swift` uses Apple Vision for hand joints, then handwritten distance ratios and finger combinations for gesture labels. These are different classifiers despite matching label names. Its confidence is derived from joint confidence, not a learned probability for the gesture category.
- Python adds a 0.40-second hold and 0.15-second neutral release before rearming. This is command gating, not proof of flicker-resistant classification. Current PC configuration disables Closed_Fist and Victory, so the PC demo does not establish reliable fist control.
- The phone currently names an index-only pose Pointing_Up without checking its direction. The requested up/down controls need explicit directional handling.

## Recommendation

If the PC recognizer is the observed working baseline, reproduce its MediaPipe model on iOS, then add directional pointing and temporal stabilization for the three requested commands. MediaPipe has an official on-device iOS GestureRecognizer integration. Its canned categories lack Pointing_Down; custom classification or a direction-independent index-point detector followed by an up/down direction check is needed. Compare both directions on actual phones before claiming parity or improved accuracy.

Reference: https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer/ios

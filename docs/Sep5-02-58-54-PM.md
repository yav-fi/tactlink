# Shared world knowledge and mission effectiveness layer

Completed: Saturday, September 5, 2026 at 2:58:54 PM EDT (America/New_York).

## Prompt

Implement the next major layer of the local-first distributed autonomy demo:
node-local imperfect world beliefs, network-carried observations, spatial
coverage and information freshness, outcome-derived mission effectiveness,
priority-aware degradation, replay and a measured centralized baseline, plus
practical improvements to leases, external workers, relay placement, generic
resources, policy, optional Ed25519 authentication, and Cesium explanations.

## What changed

- Added typed, extensible observations and a `WorldBelief` owned independently
  by every `DroneNode`. Beliefs merge deterministically by timestamp,
  confidence, source, and observation ID.
- Added range-limited simulator sensing, circular SEARCH coverage grids,
  half-life freshness decay, confidence, provenance, and anti-entropy
  `WORLD_UPDATE` messages over the existing delayed/lossy/partitionable
  network. Moving-entity truth is no longer supplied to every node globally.
- Replaced SEARCH lane completion as the success signal with actual sensed
  coverage. Added task-specific effectiveness for SEARCH, WATCH, FOLLOW,
  RELAY, and motion tasks, plus priority-weighted overall effectiveness kept
  separate from resource capability.
- Added objective degradation/recovery and resource-reprioritization events.
- Added revisioned ownership leases with deterministic IDs, renewal, expiry,
  stop-on-expiry behavior, and conflict ordering by revision, expiry, then node
  ID.
- Added deterministic scored relay candidates and distinct targets for
  multiple relay nodes/components.
- Added a reliable WebSocket external worker transport. The host retains truth,
  physics, and sensing; the worker receives only local measurements,
  observations, delivered messages, mission data carried through those
  messages, and time, then returns messages and `MotionIntent`.
- Added JSONL run recording, replay inspection, and same-seed baseline/fabric
  benchmark modes with human-readable and JSON results.
- Added generic node resource descriptors, local deterministic motion policy,
  and optional seeded Ed25519 development identities/message verification.
- Extended Cesium and the lightweight console with coverage/freshness,
  confidence, per-node belief counts, effectiveness, filtered timeline, and
  network-health history.
- Updated the deterministic demo to exercise interference, relay movement,
  control loss, drone loss, partition/heal, reconciliation, GPS outage, and
  replay recording through 55 simulated seconds.

## Notes and limitations

- This remains a deterministic software simulation, not an operational flight
  system. Sensor geometry is range/cell based, RF quality is heuristic, and the
  external worker path is synchronous per simulation tick.
- Collective mission effectiveness is an operator/debug aggregate of online
  node beliefs. It does not inject that aggregate back into autonomy.
- Reconciliation is eventual and best-effort, not consensus. Short-lived
  duplicate work is allowed during partitions; leases reduce it but do not
  prove exclusive ownership.
- The baseline continues already assigned work after control loss but cannot
  peer-auction replacements, actively reposition relays, or reconcile beliefs.
- Ed25519 mode provides local manifest authentication only; it is not a cloud
  PKI, certificate lifecycle, secure hardware integration, or deployment-ready
  security boundary.
- Cesium consumes live state and provides timeline/history visualization;
  recorded replay is currently inspected via the replay CLI rather than a
  browser scrubber.

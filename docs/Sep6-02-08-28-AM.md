# Modern gesture flight polish

Completed: 2026-09-06 02:08:28 AM EDT (-0400)

## Prompt

Polish the main Cesium drone experience: replace the oversized planner status
with a compact bottom control dock, move the gesture guess into that dock, make
the drone more realistic, use closed fist to rotate its heading, smooth and
speed up automatic flight, keep the follow camera subtly moving, and replace
the permanent red route line with short-lived red particle dots.

## What changed

- Removed the waypoint-planner overlay and its automatic bridge startup from
  the primary `./start` flow. The optional standalone bridge remains available
  for integration work.
- Integrated camera state, gesture guess, confidence, hold progress, command
  feedback, and telemetry into the compact bottom dock.
- Added a deliberate closed-fist mapping that performs an eased 90-degree
  clockwise heading turn. Typed `rotate right` / `rotate left` commands now use
  the same turn behavior.
- Added acceleration and arrival braking for goto/return flight, smooth orbit
  ring approach, cruise-speed orbit motion, and a faster minimum gesture dash.
- Replaced the continuous visible route with 28 red light particles that fade
  over 2.8 seconds. Full route samples remain hidden for replay.
- Changed the automatic follow camera from a complete stop to a restrained
  sinusoidal side-to-side drift while it continuously looks at the fleet.
- Rebuilt the bundled GLB as a rounded graphite/black quadcopter with a smoked
  canopy, red accent, exposed arms, motor pods, landing rails, and slim crossed
  propeller blades; reduced the display enlargement and silhouette strength.
- Updated the local-mode documentation and regression tests.
